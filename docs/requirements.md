## F01. 계정·공통 화면

- [ ] Firebase Authentication 로그인과 앱 최초 사용자 초기화. 닉네임, 친구 코드, 기본 알 또는 반려동물, 포인트·설정을 준비한다.
- [ ] 홈·상점·친구·도감·기록의 하단 탭 이동과 현재 탭 표시. 알림함·친구 방문·알 돌보기 화면으로 이동하고 뒤로 돌아온다.
- [ ] 로딩, 빈 목록, 통신 실패, 권한 안내, 만료된 로그인 상태를 표시한다.
- [ ] 프로필·현재 반려동물·보유 포인트·읽지 않은 알림을 관련 화면에서 일관되게 갱신한다.
- [ ] 재접속 시 서버에 저장된 상태를 불러온다. 로그인 방식, 기본 캐릭터 선택과 계정 복구 방법은 미결정이다.

## F02. 걸음 동기화와 산책 기록

- [ ] Android와 iOS의 걸음 데이터 접근 동의를 받고, 기기에서 일자별 걸음 합계를 읽는다.
- [ ] 앱 실행·복귀 시 합계를 서버에 동기화하고, 당일 목표와 진행률을 홈에 표시한다. 백그라운드 동기화는 OS 권한·제한에 따라 가능한 경우에 실행한다.
- [ ] 일간·주간 보기, 날짜 이동, 그래프, 총걸음·평균·목표 달성 횟수·이전 기간 대비 변화를 표시한다.
- [ ] 걸음 수로 포인트를 적립하고 현재 반려동물의 성장에 반영한다. 같은 데이터 재전송은 중복 보상하지 않는다.
- [ ] 동기화 불가·권한 미설정·미기록 일자를 0걸음과 구분해 표시한다. 수동 입력 허용 여부는 미결정이다.
- [ ] 기기 교체, 이전 날짜의 지연 동기화, 걸음 데이터 감소·수정 시 처리 규칙을 적용한다. 임시 규칙은 [API 명세](api-spec.md#걸음-동기화와-산책-기록) 참조.

## F03. 반려동물과 성장

- [ ] 알·아기·청소년·어른 단계, 이름·생존 일수·기분 문구, 현재 성장 진행률을 표시한다.
- [ ] 포만감·행복·청결·건강 수치를 표시하고 먹이·청소·놀기·약·재우기 행동을 처리한다.
- [ ] 보관함 아이템이 필요한 행동은 보유 여부를 검사하고 아이템과 상태를 함께 갱신한다.
- [ ] 걸음과 돌봄으로 성장 규칙을 적용하고, 기준 도달 시 부화·단계 전환과 알림을 생성한다.
- [ ] 보유 반려동물을 구분하고 현재 돌보는 개체를 선택한다. 다수의 알이 생길 때 필요한 보조 기능이며 전용 화면 디자인은 아직 없다.
- [ ] 알 화면에 누적 걸음, 부화 목표, 남은 걸음과 알→어른 여정을 표시한다.

## F04. 상점·아이템·포인트

- [ ] 전체·먹이·희귀 알·장난감 분류, 상품 이미지·효과·가격을 표시한다.
- [ ] 보유 포인트와 당일 적립 포인트를 표시하고, 상품 구매 시 잔액·보관함을 동시에 갱신한다.
- [ ] 잔액 부족, 품절 또는 판매 중지, 중복 요청을 처리한다.
- [ ] 보관함에서 아이템 수량을 조회하고, 돌봄·알 생성·친구 선물에 사용한다.
- [ ] 포인트 지급·사용 이력을 저장한다. 실제 가격, 아이템 효과, 환불·유효기간은 미결정이다.

## F05. 친구

- [ ] 내 친구 코드를 표시·복사하고, 코드 입력 또는 QR 인식으로 친구를 추가한다. QR은 친구 코드를 담은 표시 수단이다.
- [ ] 친구 목록·총 수·최근 접속·반려동물 단계·공개된 오늘 걸음 수를 표시한다.
- [ ] 친구 집 방문 및 친구 반려동물·돌봄 정보를 표시한다.
- [ ] 보관함 아이템을 친구에게 선물하고, 발신자와 수신자의 보관함 및 알림을 갱신한다.
- [ ] 친구 추가의 수락 필요 여부, 공개 범위, 차단·삭제와 선물 제한은 기획 결정 후 적용한다. 이 설계는 코드 입력 시 양쪽이 즉시 친구가 되는 방식을 임시로 사용한다.

## F06. 청혼·가족·새 알

- [ ] 서로 친구인 어른 반려동물의 청혼 가능 여부와 상태를 확인한다.
- [ ] 청혼을 보내고 상대의 수락·거절을 처리한다. 발신자는 수락 전 청혼을 취소할 수 있다.
- [ ] 청혼과 결과 알림에서 상세 화면으로 이동한다. 중복 요청이나 동시에 처리된 요청에 일관된 결과를 반환한다.
- [ ] 수락 시 가족 관계와 새 알을 생성하고 부모 정보를 연결한다. 이 설계는 **각 사용자에게 별도 알 1개**를 임시로 부여하며, 실제 소유 방식은 확정이 필요하다.
- [ ] 부모의 외형·돌봄 점수 조합을 미리 보여주는 화면이 있다. 상속 공식, 미리보기의 정확도와 생성 결과는 미결정이다.

## F07. 친구 도감

- [ ] 전체 종 수, 발견 수와 발견률을 표시한다.
- [ ] 전체·발견·미발견 필터, 검색, 발견 순 목록, 페이지 이동을 제공한다.
- [ ] 종별 이름·이미지·발견 여부·첫 발견 일시와 친구 정보를 표시한다.
- [ ] 임시 설계에서는 내 반려동물이 어른이 되거나 친구 방문으로 어른 종을 처음 만나면 발견 처리한다. 정확한 발견 조건과 미발견 정보 공개 범위는 미결정이다.

## F08. 알림

- [ ] 돌봄·부화·성장·청혼·선물·산책 요약 알림을 저장하고 목록·읽지 않은 수를 표시한다.
- [ ] 전체·안 읽음 필터, 개별 읽음, 모두 읽음, 관련 상세 화면 이동을 제공한다.
- [ ] 전체 푸시와 유형별 푸시 설정, 기기 푸시 토큰 등록·갱신을 제공한다. 임시 설계에서는 푸시를 끄더라도 앱 알림함은 유지한다.
- [ ] 청혼 알림의 수락 버튼 등은 알림 읽음과 별도로 실제 업무 API를 호출한다.

## 구현 단위와 선행 관계

| 단계 | 작업 단위 | 선행 조건 |
| --- | --- | --- |
| 1 | 공통 앱 틀, 인증, 사용자·반려동물 초기화 | 로그인 정책, 기본 알 정책 |
| 2 | 기기 걸음 연동, 일별 기록과 홈 | 목표·동기화·보상 규칙 |
| 3 | 반려동물 성장·돌봄, 상점·보관함 | 단계·상태·아이템 효과 |
| 4 | 친구 코드·목록·방문·선물 | 친구 관계와 공개 정책 |
| 5 | 청혼·가족·알, 도감 | 청혼 조건·알 소유·도감 발견 조건 |
| 6 | 알림함·푸시와 화면별 예외 처리 | 이벤트 종류·수신 정책 |

이는 의존 관계에 따른 분할이며 출시 범위의 우선순위는 별도 결정이 필요하다.
