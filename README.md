# 걸음 다마고치

걸음 수로 다마고치를 키우며 꾸준히 걷는 습관을 만드는 모바일 앱입니다.

## 프로젝트 소개

걷기를 꾸준히 실천하기 어렵다는 문제에서 출발했습니다. 매일 걸으며 캐릭터를 성장시키고 돌보는 재미를 통해 걷는 습관을 만드는 것이 목표입니다. Android와 iOS에서 사용할 수 있도록 개발할 예정입니다.

## 주요 기능

아래 기능은 발표 자료를 바탕으로 한 **개발 예정 기능**입니다.

- **걸음 기록과 성장**: 걸음 수를 기록하고, 다마고치를 알에서 성체까지 키웁니다.
- **돌봄**: 밥을 주고 청소하거나 놀이를 하며 캐릭터를 돌봅니다.
- **친구와 결혼**: 친구의 다마고치와 교류하고, 결혼을 통해 새로운 알을 얻습니다.
- **도감과 통계**: 캐릭터를 수집하고 걸음 기록을 확인합니다.

## 예상 화면

- **홈**: 오늘의 걸음 수, 성장도, 캐릭터 상태와 돌봄 기능을 보여줍니다.
- **친구**: 친구 코드나 QR로 친구를 추가하고, 방문·선물·결혼 기능을 이용합니다.
- **도감·통계**: 수집한 캐릭터와 일별·주간 걸음 기록을 확인합니다.
